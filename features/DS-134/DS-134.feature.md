# DS-134 — Program name max length on create

**Jira:** [DS-134](https://legionqaschool.atlassian.net/browse/DS-134)  
**Parent:** DS-1 Create new academic program  
**Type:** Bug — names over 100 characters are accepted without validation

## Gherkin

```gherkin
Feature: DS-1 — Program name length validation (DS-134)

  Scenario: Program name at exactly 100 characters is accepted
    Given I am logged in as admin
    And I am on the Programs page
    When I open the New Program modal
    And I fill Program Name with a 100-character string
    And I click Create
    Then the modal closes
    And I see the program in the list

  Scenario: Program name over 100 characters is rejected
    Given I am logged in as admin
    And I am on the Programs page
    When I open the New Program modal
    And I fill Program Name with a 101-character string
    Then the Create button is disabled or a validation error is shown
    And no program with that name appears in the list
```

## Notes

- Expected max length: **100 characters** (per DS-1 validation AC / ticket-003 TC-201–TC-202).
- Current product behavior (DS-134): over-limit names are accepted — test uses `test.fail` until fixed.
